# Conciliação financeira — download da tarefa padrão

Concilie **uma conta bancária em reais durante um mês** e receba uma planilha Excel com modelo fixo. O assistente pergunta os dados necessários antes de processar os movimentos.

**[⬇ Baixar o arquivo de instruções](https://github.com/ubirajaratheodoro/smartchat/raw/refs/heads/main/downloads/conciliacao-financeira/especificacao_conciliacao_financeira_padrao_v002.md)**

Arquivo **v002**, versão da tarefa **2.0**, estruturado conforme o padrão v011.

## Como começar

1. Baixe o arquivo e mantenha a extensão `.md`. Se o navegador exibir o texto, use **Salvar como** ou abra [a página do arquivo](especificacao_conciliacao_financeira_padrao_v002.md) e clique em **Download raw file**.
2. Anexe-o em uma conversa com SmartChat.
3. Escreva:

> Faça minha conciliação financeira seguindo o arquivo de instruções anexado.

O assistente perguntará onde estão os extratos e comprovantes, qual período conciliar e as demais informações necessárias. Você não precisa editar o arquivo nem escolher o formato da planilha.
